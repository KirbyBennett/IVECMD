iVECMD Help

Quick start

  • Overview Plot: A fixed map of every star that passes the active filters. The green rectangle marks the region shown in the Detail View — drag it around the overview to move the Detail View, scroll anywhere on the overview to grow or shrink it (zooming the Detail View out or in), and it also follows along as you pan and zoom the Detail View itself. It can even slide off the edge of the overview; use Center Detail View in the Actions card to bring it back to the middle. The gold arrow in the top right is the interstellar reddening vector — the displacement AV = 1 mag of dust extinction produces, using the Gaia-band extinction coefficients calibrated on red clump stars (Wang & Chen 2019): ΔG = 0.79, ΔE(BP−RP) = 0.41. Drag it anywhere on the overview to compare its direction with a feature; its length and angle track the data scale. Hide it from the Display card.
  • Detail View: Shows the stars within the selected region. Drag to pan, scroll to zoom around the cursor, and use the slider to adjust line thickness.
  • Plot style: The Display card switches both plots between Lines (each star's variability segment) and Points (a single dot at each star's average color and magnitude from the input table). Points keep the same ρ color and significance opacity as the lines, and the thickness slider sets the dot size.
  • Zooming: Use + and − keys to zoom the detail view in and out, and 0 to reset. To stretch one axis independently (in the Detail View or the CMD), scroll while hovering over that axis — or hold Shift for x-only / Alt for y-only zoom inside the plot. In the epoch-CMD dialog you can also use the X −/+ and Y −/+ buttons in the corner of the plot to zoom each axis on its own. Dragging the CMD's axis strips pans that axis alone.
  • Filters: Restrict the view to bluing (ρ>0) or reddening (ρ<0) systems, and tighten the significance (p-value) or correlation strength (|ρ|) thresholds. The dual sliders cut on parallax distance and on galactic latitude |b| — the angular distance from the galactic plane — so you can exclude the crowded plane (raise the min) or keep only sources near it (lower the max). Both panels and the export honor the active filters. Reset Filters returns every control to its startup position.
  • Saved Settings: Once the Filters are dialed in, type a name and press Save Current Settings to keep that whole arrangement — Filters, the Display card, the catalog overlays, the plot-image options and the current view. Pick it from the list later and press Load to come straight back to it. Set ★ marks one set as the startup configuration: it is applied automatically every time the app opens, and Reset Filters then returns to it instead of the factory values. Export File… / Import File… put the same thing in a .json file, for keeping several configurations beside a project or handing one to a collaborator. Custom ID lists travel along up to 20,000 IDs; above that only the on/off state is kept, and a catalog whose file is missing is reported and left off.
  • Variable-star & custom lists: Toggle a catalog (Cepheids, RR Lyrae, …) to highlight its members on both plots, or use only to restrict to it. Under Custom IDs, Load ID list… or Paste IDs… takes any list of Gaia DR3 source IDs (a bare list, or a whole table — extra columns and a header row are ignored) and highlights the matches in white.
  • Inspecting a star: Click any line in the Detail View. The app queries VizieR live for that star's Gaia DR3 epoch photometry and builds its color–magnitude diagram, with sigma clipping and a slope fit. Scroll on the CMD to zoom past clipped outliers, drag to pan, and double-click (or Reset Zoom) to restore the full view.
  • Light curves: The Light Curves button in the CMD dialog shows the raw multi-epoch photometry — G, BP, and RP magnitudes versus time plus the BP−RP color curve — after the quality cuts. Every panel is interactive: drag to pan, hold Shift or Ctrl and scroll to zoom about the cursor (Ctrl both axes, Shift x-only, Ctrl+Alt y-only — plain scrolling just scrolls the dialog), and double-click to reset that panel — or use Reset Views in the dialog header to reset every panel at once (also available in the Phase Fold dialog).
  • Phase folding: Inside the CMD dialog, the Phase Fold button computes generalized Lomb–Scargle periodograms for G, BP, and RP, folds each light curve at its own best period, multiplies the three periodograms together, and folds the BP−RP color curve at the combined best period. Period ×2 / ÷2 re-fold everything at harmonics of the peaks — useful when the periodogram locks onto half the true period, as it often does for eclipsing binaries. The standard grid searches down to 1-hour periods; tick high-res freq grid to extend the search to 5-minute periods with a much denser frequency grid (slower — only needed for short-period pulsators; it unticks itself each time the dialog opens). Right-click any periodogram to re-fold its row at that period — the click snaps to the strongest peak within a few pixels, so you don't have to hit a narrow peak exactly (band periodograms re-fold their own band; the combined one re-folds the BP−RP curve; reopening the dialog restores the GLS peaks). Each periodogram and folded panel is interactive: drag to pan, hold Shift or Ctrl and scroll to zoom, double-click to reset.
  • Searching: Paste a Gaia DR3 source ID into the Search & Selection card (or press /) to center both plots on that star. One ID per search, but searches add up: run a second search and the first star stays selected, so several sources can be compared on one plot — the box takes a bare ID, a "Gaia DR3 …" label, or a whole table row (the RA/Dec alongside it are ignored). Paste two IDs at once and it says so rather than silently picking one. A searched star is selected even when it fails the active filters: selecting pins it, so it is drawn on both plots regardless of the cuts, and the status line says so. Clear Selection drops them all; Ctrl/Cmd+Click on one drops just that one.
  • Selecting: Click selects one star, replacing whatever was selected; Ctrl/Cmd+Click adds or removes stars without disturbing the rest. Selected stars are redrawn on top of everything else at about 2½× their normal line width, so they stay findable in a crowded field, and they count as visible for the CSV exports.
  • Saving Data: Enter a filename and use the Export card to download the visible, selected, or filtered sources as CSV. Save Plot Images writes both panels as separate high-resolution figures in the chosen format (PNG, JPEG, or PDF), re-rendered on a white background with paper-sized fonts (dark-mode colors are swapped for print-legible ones) so they drop straight into a paper or slide. Each figure takes the shape of its panel on screen — reshape the window to frame a feature and the saved figure is framed the same way, rather than being squeezed into a fixed page. Untick Colorbar in saved plots for figures that carry their own caption or share one legend; the page narrows to match so no empty band is left behind. The two figures arrive together in a single .zip, because a browser only lets a page save one file per click — sending them separately meant the second one was silently dropped.

Keyboard shortcuts

  • F fit all data in the Detail View · 0 reset to the default window (the hot subdwarf clump)
  • +/− zoom the detail window
  • / focus the search box · H toggle this help
  • S export the current selection · Esc clear selection / close dialogs
  • Ctrl/Cmd+Z undo view · Ctrl/Cmd+Shift+Z redo view
  • While a dialog is open, only Esc (and H for this help) stay active — the rest pause so they can't act on the plots underneath.

What am I looking at?

Each line segment represents one star observed many times by ESA's Gaia space telescope. The horizontal axis is the star's color (GBP−GRP, blue→red), and the vertical axis is its absolute brightness (GMAG). A star that varies traces a small path in this diagram: the segment shows the direction and size of that path.

Blue lines are stars that get bluer as they brighten; red lines get redder as they brighten. Bolder, more opaque lines have a more statistically significant correlation (smaller Spearman p-value).

For astronomers

Source list: Gaia DR3 epoch photometry (VizieR I/355/epphot), filtered to ρ ≠ 0 and ≥ 6 epochs. Clicking a source runs: flux→mag error propagation, distance modulus from DR3 parallax, iterative 4σ flux clip, SNR > 1 cut on G/BP/RP, an std-ratio slope-stability clip (10% threshold), and an unweighted linear fit to the kept epochs.

Serving this file

For the dataset to auto-load and VizieR queries to work smoothly, serve this folder over HTTP, e.g. python3 -m http.server 8000 then open http://localhost:8000/index.html. If opened directly from disk, you can drag & drop or browse for the data table instead.
